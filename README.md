# Mechanistic Interpretability

This repo contains my personal study of the research in the area of mechanistic interpretability.

## Virtual Environment
First, please create a virtual environment for executing the Python script.

(1) Create a new virtual environment directory. The directory name `venv` can be replaced with any names.
```
python -m venv ./venv
```
(2) Activate the virtual environment.
```
source venv/bin/activate
```
(3) Install the required packages in `requirements.txt`.
```
pip install -r requirements.txt
```
